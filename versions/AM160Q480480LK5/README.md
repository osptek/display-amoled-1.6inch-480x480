## 规格参数

| 项目 | 规格 |
| ---- | ---- |
| 尺寸 | 1.6 英寸 |
| 类型 | AMOLED |
| 分辨率 | 480×480 |
| 外形尺寸 | 43.40 x 43.11 mm |
| 有效显示区域 | 39.12 x 39.12 mm |
| 接口 | QSPI/MIPI |
| 驱动 IC | ST7802 |
